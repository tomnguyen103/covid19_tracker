# COVID-19 Tracker

A real-time COVID-19 dashboard that displays global and country-level statistics including confirmed cases, recoveries, and deaths.

## Features

- **Global overview** — live stats for total confirmed cases, recoveries, and deaths worldwide
- **Country filter** — select any country to view its individual statistics
- **Historical chart** — visualizes the progression of cases and deaths over time
- **Live data** — powered by the [disease.sh](https://disease.sh) open disease data API

## Built With

- React
- Vite
- Chart.js
- Material UI
- Axios

## Getting Started

```bash
npm install      # install dependencies
npm start        # start the dev server at http://localhost:3000
npm run build    # create a production build in /build
npm run preview  # preview the production build locally
```
